## 5. 프로덕션 상시 배포 현황 (Production Deployment)

### 5.1 배포 아키텍처

```
[ Internet ] ──HTTPS──▶ talklite-frontend (Caddy, 80/443) ──▶ talklite-backend (Spring Boot, 8080)
                              ▲ 정적 파일(React dist) 서빙 + HTTPS 자동      │
                              └─ /api·/ws 프록시 ──────────────────────────┘
                              └─ Redis 7 (내부 전용)  ── talklite-redis
                              └─ MariaDB 11 (내부 전용) ── talklite-mariadb
```

- 외부 노출은 **Caddy(80/443) 하나뿐**, backend/redis/mariadb는 내부 네트워크 비공개
- 컨테이너 4개: `talklite-redis`, `talklite-mariadb`, `talklite-backend`, `talklite-frontend`

### 5.3 배포 파일 (소스 저장소)

- `backend/Dockerfile` + `backend/.dockerignore` — Spring Boot multi-stage(arm64), `application.yml` 수정 없음(compose 환경변수 오버라이드)

### 5.4 운영 가이드

| 항목 | 내용 |

### 5.5 주요 함정 해결 기록

- **Vercel/Cloudflare 불가**: JVM 상주 + STOMP WebSocket + 자체 DB → 서버리스 미지원
- **공인 IPv4 토글 비활성화 버그**: 인스턴스 화면 안에서 VCN 생성 시 발생 → VCN/공용 서브넷을 먼저 따로 생성 후 "Select existing"으로 해결
- **Windows SSH 키 거부**: `UNPROTECTED PRIVATE KEY FILE` → `icacls /inheritance:r` + `/grant:r "kimmh:F"`로 해결
