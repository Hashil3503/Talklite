## 4. 인수인계 체크리스트 (Checklist for Next Developer)

1. [x] **Redis & MariaDB Docker Compose:** `docker compose up -d`로 Redis 7 + MariaDB 11 즉시 기동 가능.
2. [x] **REST Principal 보안 인증 (DEF-01):** `@AuthenticatedUser`를 통해 HTTP `Authorization: Bearer <token>`이 강제되며, 비인가/타인 사칭 차단.
3. [x] **Relay-Only 메시징 원칙:** 백엔드는 이벤트 처리 후 Redis Pub/Sub 채널로만 전파하고, 브로드캐스트는 `RedisMessageSubscriber`가 단독 수행.
4. [x] **Room GC & 방 삭제 가드:** 휘발성 방 퇴장은 `gc.lua`(SCARD==0 가드), 방장 명시적 폭파는 `destroy.lua`(강제 일괄 파기)로 명확히 분리 구현됨.
5. [x] **영구 방 고아화 방지 & 자동 승계 (DEF-02):** 0명이 된 영구방은 `markOrphan`으로 고아 상태로 유지되며, 최초 재입장 유저가 방장 권한(`👑`)을 자동 승계.
