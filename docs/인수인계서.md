    1. **3종 플러그형 노이즈 엔진 (`frontend/src/lib/noise/` & `public/wasm/`):** RNNoise (게이밍 타건음 차단), DeepFilterNet (스튜디오 고음질), Speex DSP (초절전) 탑재 및 10ms (480 샘플 @ 48kHz) 오디오 버퍼링.
    2. **원자적 핫스왑 & Destination 불변 보장 (`VoiceAudioEngineImpl`):** `MediaStreamDestination` 노드를 불변으로 유지하여 WebRTC 송신 트랙(`replaceTrack`) 유실을 방어하고, `denoiseSeq` 가드와 5ms 선형 게인 크로스페이드(`linearRampToValueAtTime`)로 팝 노이즈 차단.
    3. **장치 교체 무단절 복원 (`rewireInputSource`):** 마이크 장치 핫스왑(`replaceInput`) 시 잡음 제거 활성 상태에 맞춰 파이프라인 자동 재배선.
    4. **스마트 영구 기억 & Fallback (`voiceStore.ts` & `VoiceBar.tsx`):** `localStorage` 화이트리스트 검증 기반 설정 영구 보존, WASM 로드 실패 시 무단절 바이패스 자동 복귀, `role="switch"` 접근성 UI.

## 4. 인수인계 체크리스트 (Checklist for Next Developer)

1. [x] **Redis & MariaDB Docker Compose:** `docker compose up -d`로 Redis 7 + MariaDB 11 즉시 기동 가능.
2. [x] **REST Principal 보안 인증 (DEF-01):** `@AuthenticatedUser`를 통해 HTTP `Authorization: Bearer <token>`이 강제되며, 비인가/타인 사칭 차단.
3. [x] **Relay-Only 메시징 원칙:** 백엔드는 이벤트 처리 후 Redis Pub/Sub 채널로만 전파하고, 브로드캐스트는 `RedisMessageSubscriber`가 단독 수행.
4. [x] **Room GC & 방 삭제 가드:** 휘발성 방 퇴장은 `gc.lua`(SCARD==0 가드), 방장 명시적 폭파는 `destroy.lua`(강제 일괄 파기)로 명확히 분리 구현됨.
